# Расписание ВАВТ → виджет на iPhone

Виджет для [Scriptable](https://scriptable.app) с расписанием группы **Б26М-ММВЯ.2** (ФВМ, 1 курс).

```
vavt.ru/schedule  ──PDF──▶  GitHub Actions (parser/)  ──▶  data/schedule.json  ──▶  Scriptable-виджет
```

- Раз в 3 часа GitHub Actions берёт со страницы курса PDF на текущие две недели, разбирает таблицу и коммитит `data/schedule.json` (и `data/schedule.txt` — то же самое текстом).
- Виджет на телефоне только читает этот JSON и кеширует его на случай, если нет сети.

## Установка виджета

1. Поставь **Scriptable** из App Store.
2. Создай новый скрипт и вставь туда содержимое `widget/vavt-schedule.js`.
3. Проверь, что в строке `DATA_URL` в начале скрипта стоит адрес твоего репозитория.
4. Запусти скрипт один раз в приложении: появится превью и вся неделя текстом.
5. На домашнем экране: долгое нажатие → «+» → Scriptable → выбери размер → «Изменить виджет» → Script: `vavt-schedule`.

Размеры:
- **маленький** — следующая пара крупно: «через 25 мин» или «идёт · до 11:50», аудитория, что дальше;
- **средний** — пары на сегодня (вечером — на завтра), с аудиториями;
- **большой** — вся неделя: каждый день карточкой в два столбца, сегодня подсвечено, идущая пара — зелёная.

Ненужные пары (сейчас — «Русский как иностранный») прячутся списком `HIDE` в начале скрипта.

В поле Parameter можно написать `next`, `today` или `week`, чтобы поменять режим.

## Другая группа или курс

В репозитории: Settings → Secrets and variables → Actions → **Variables**:

| Переменная | Пример | Что это |
|---|---|---|
| `GROUP` | `Б26М-ММВЯ.2` | шифр группы, как в шапке таблицы |
| `COURSE` | `2 курс` | курс |
| `FACULTY` | `ФВМ` | факультет |
| `PROFILE` | `ММВЯ` | кусок имени PDF-файла |

После этого: Actions → «Обновить расписание» → Run workflow.

Локальная проверка:

```bash
pip install -r parser/requirements.txt
python parser/vavt_schedule.py             # скачать с сайта и напечатать
python parser/vavt_schedule.py --pdf week.pdf --group "Б26М-ММВЯ.1"
```

## Что может сломаться

- **Сайт поменял вёрстку или вид таблицы** — workflow упадёт с ошибкой «Не нашёл ни одной пары», виджет продолжит показывать последнее удачное расписание. Таблицы 2 курса ФВМ уже свёрстаны иначе, их парсер пока разбирает с ошибками.
- **GitHub отключает запуск по расписанию**, если в репозитории 60 дней не было коммитов (например, летом). Включается обратно на вкладке Actions.
